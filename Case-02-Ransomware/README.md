# Case 02 — Ransomware Investigation

## Case Status

🟡 Investigation in Progress

## Investigation Overview

This case documents a ransomware investigation conducted using Splunk and endpoint telemetry. The objective is to identify suspicious activity, reconstruct the attack timeline, determine the impact, extract indicators of compromise, and recommend containment and remediation actions.

## Investigation Objectives

- Identify the compromised host and affected accounts
- Investigate suspicious processes and commands
- Analyze parent-child process relationships
- Identify ransomware-related files and artifacts
- Examine suspicious network connections
- Extract indicators of compromise
- Reconstruct the attack timeline
- Map observed behavior to MITRE ATT&CK
- Recommend containment and remediation actions
